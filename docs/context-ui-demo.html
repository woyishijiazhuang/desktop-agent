各方案对比小结

方案 形态 参考产品 优点 缺点
A · 输入框顶部细线 3px 细色线 —（当前实现） 最不打扰 突兀、无数字、信息量低
B · 底部状态栏 分格条 + 百分比 + 模型 Claude Code HUD / Cursor 常驻、信息完整、可读性强 占一行高度
C · 消息区顶部细条 顶部横条 Claude.ai 开场即见、不遮挡 滚动后不可见
D · 输入框内嵌文本 一行小字 OpenAI Codex 最克制、零结构 不够直观（无图形）
E · 分段上下文条 分段色条 + 图例 claude-context-visualizer 信息密度最高 对普通用户偏重
F · 压缩按钮角标 百分比徽标 —（侧栏集成） 复用入口、零行高 不够显眼

我的建议：若只选一个，B · 底部状态栏是市面上最主流的形态（Claude Code 生态已验证）， 可降噪为「一条细状态行：分格条 + 百分比」；若想最克制，D · 内嵌文本最接近 Codex。 也可以组合：常态只显示 D 的小字，达到阈值时自动浮现 B 的状态行 + 提示。
